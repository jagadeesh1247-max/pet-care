# 🐾 Paws & Hearth — Pet Wellness, Training & Grooming Website

A responsive, modern pet-care website built with **pure HTML5 and CSS3** (zero JavaScript), designed to showcase veterinary services, daily pet-care tips, specialist profiles, clinic hours, an appointment request form, and contact information.

🌐 **Live Demo:** [https://tangerine-rabanadas-a443fd.netlify.app](https://tangerine-rabanadas-a443fd.netlify.app)

---

## ✨ Features

- **Pure HTML5 & CSS3 Architecture:** Built without JavaScript frameworks or script tags, using semantic HTML5 elements and modern CSS3 layout techniques.
- **Cohesive Visual Design System:** Uses CSS custom properties (`:root` variables) pairing a warm cream background (`#FAF8F5`), deep sage green (`#2F4F42`), terracotta accents (`#C86D51`), and Google Fonts (`Lora` and `Plus Jakarta Sans`).
- **CSS-Only Responsive Navigation:** Sticky header with smooth anchor navigation and a mobile menu toggle implemented purely with HTML and CSS.
- **Complete Pet-Care Sections:**
  - **Hero Banner:** Highlights Fear-Free certified care, key clinic stats, call-to-action buttons, and a featured companion visual.
  - **Available Services:** Cards for *Preventive Wellness & Vet Exams*, *Professional Grooming & Spa*, *Positive Behavioral Training*, and *Pet Nutrition & Dental Care* with pricing, duration, and key inclusions.
  - **Pet-Care Tips:** Actionable daily care advice covering nutrition & hydration, dental hygiene, mental enrichment, and seasonal protection.
  - **Specialists Team:** Profiles for the lead veterinarian, certified pet trainer, and master grooming specialist with credentials and focus areas.
  - **Clinic Info & Appointment Form:** Operating hours, arrival guidelines, after-hours emergency triage note, and an accessible HTML form for requesting visits.
  - **Contact & Footer:** Clinic address, phone and email links, quick links, and care specialties.

---

## 🛠️ Tech Stack

- **HTML5** (Semantic markup & native form controls)
- **CSS3** (Custom properties, Flexbox, CSS Grid, responsive media queries)
- **Google Fonts** (`Lora` & `Plus Jakarta Sans`)
- **Netlify** (Static site hosting & deployment)
